## 六、核心算法详解

### 6.1 路径规划 — TRRT* (Temperature-based RRT*)

**文件**: `jaka_env.py` → `trrt_star_optimized()`

| 参数 | 默认值 | 说明 |
|---|---|---|
| `max_iter` | 5000 | 最大迭代次数 |
| `step_size` | 0.1 | 采样步长 |
| `radius` | 0.5 | 邻域搜索半径 |
| `init_temp` | 1.0 | 初始温度 |
| `k0` | 0.1 | 目标偏向起始概率 |
| `alpha` | 0.95 | 温度衰减系数 |
| `beta` | 1.1 | 温度增长系数 |

**算法流程**:
1. 以概率 k 采样目标点或随机配置
2. 用 KD-Tree 找最近邻节点
3. 向采样方向扩展 step_size
4. 温度机制拒绝过远的跳跃 (exp(-delta/T) < random)
5. 邻域重连 (rewiring) 优化路径代价
6. 到达目标后执行路径平滑 (_smooth_path)

### 6.2 运动控制 — RmpFlow

**文件**: `jaka_env.py` → `JakaRmpFlowController.__init__()`

```python
RmpFlow(
    end_effector_frame_name="gripper_center",
    maximum_substep_size=0.01,
    ignore_robot_state_updates=True,
    robot_description_path="JAKA_C5_With_DH_PGI.yaml",
    urdf_path="JAKA_C5_With_DH_PGI.urdf",
    rmpflow_config_path="JAKA_C5_With_DH_PGI_rmpflow.yaml"
)
```

**功能**: 反应式运动策略，实时避障 + IK 求解 + 轨迹跟踪

### 6.3 夹爪控制 — 力传感器自适应抓取

**文件**: `jaka_env.py` → `forward_and_track()`

```python
# 夹爪控制逻辑
left_eff, right_eff = self.get_gripper_efforts()
if left_eff >= effort_threshold or right_eff >= effort_threshold:
    if self.overlap_prim_path and not self.gripper_is_close:
        self.close_gripper()     # 禁用刚体 + 记录相对位姿
    self.gripper_is_close = True
else:
    if self.gripper_is_close:
        self.open_gripper()      # 重新启用刚体
    self.gripper_is_close = False
```

### 6.4 视觉检测 — YOLOv8 + 深度 + 倾斜角

**文件**: `isaac_yolov8.py`

- YOLOv8 目标检测 → bbox 坐标
- 中心像素深度查询 → 3D 坐标
- Canny 边缘 + minAreaRect → 2D 倾斜角

### 6.5 坐标变换 — 相机外参

**文件**: `isaac_pose_pub.cpp` / `isaac_yolov8.cpp`

```
相机坐标系 → 机器人坐标系:
P_robot = R × P_camera + T

其中:
R = [0.9499, -0.0767,  0.3030]    (旋转矩阵)
    [0.1082,  0.9902, -0.0887]
    [-0.2932, 0.1170,  0.9489]
T = [0.5072, 0.2223, 0.3310]      (平移向量)
```

像素 → 相机坐标:
```
X_cam = (u - cx) × depth / fx
Y_cam = (v - cy) × depth / fy
Z_cam = depth
```

from transformers import AutoModel, AutoTokenizer

model = AutoModel.from_pretrained(
    '/root/inference/FM9G4B-V',

- `prompt`: 用户文本指令

## 九、机械臂接口详解

### 9.1 夹爪控制逻辑 — 增量闭合策略

```
1. 读取当前夹爪开合值 g
2. 循环执行:
   new_g = g + 0.001
   publish("/Jaka/set_gripper_value", new_g)
3. 检查 /Jaka/gripper_is_captured:
   - False → 继续增量闭合
   - True  → 停止，抓取成功
```

### 9.2 规划控制接口

| 类 | 函数 | 说明 | 调用时机 |
|---|---|---|---|
| `JakaRmpFlowController` | `plan_and_execute_trajectory(target_pos, target_rot_wxyz)` | IK → TRRT* → 样条 → 保存轨迹 | 收到新目标时 |
| | `update_trajectory_tracking(gripper_value)` | 轨迹线性插值 + 关节位置下发 | 每帧 |
| | `forward_and_track(gripper_value)` | 跟踪 + 夹爪状态机 | 每帧 |
| | `get_end_effector_pose()` | 正向解算, 返回 (pos, quat_wxyz) | 多处 |
| | `reset()` | 初始化关节/夹爪 | world.reset |
| `SimEnvironment` | `step()` | 检测新目标 → 规划 → 跟踪 → ROS 发布 | 每帧 |
| | `publish_ros_data()` | 发布 /pose /joint_states /gripper_efforts | 每帧 |
