## 1. 为什么单点深度不可靠

深度相机（RGB-D）常见无效值：

| 现象 | 数值 | 后果 |
| --- | --- | --- |
| 无回波 / 透明 / 过曝 | `NaN` / `Inf` | 反投影得垃圾坐标 |
| 传感器默认空 | `0` | `Z=0` 除零或贴脸 |
| 串扰 / 飞点 | 突然 `99`、`1e6` | 机械臂“飞出”工作空间 |

原代码：

```python
depth = float(self.depth_image[cy_i, cx_i])
if not np.isnan(depth):
    publish(...)
```

只挡了 NaN，**0 和离群大值照样进 `mycaryolo`**。

## 2. 邻域采样 + 过滤（本阶段）

### 2.1 流程

```text
目标中心 (u,v)
    → 取 window×window 邻域（默认 5）
    → 丢掉非有限值
    → 丢掉不在 (DEPTH_MIN, DEPTH_MAX) 的值
    → 有效点数 < 3 → 返回 None（不发布）
    → 否则取中位数
```

### 2.2 为什么是中位数

- 均值：一个飞点 `99` 会把深度拉飞  
- 中位数：少数离群点不影响主趋势  

### 2.3 参数与 C++ 对齐

| 参数 | 值 | 原因 |
| --- | --- | --- |
| `DEPTH_MIN` | 0.05 m | 太近多半无效 |
| `DEPTH_MAX` | 5.0 m | 场景桌面尺度；与 `isaac_yolov8.cpp` 阶段1过滤一致 |
| `window` | 5 | 覆盖 bbox 中心小块，又不至于吃到桌面 |
| `min_valid` | 3 | 全是空洞时宁可不发 |

## 4. 和坐标变换的关系

```text
Xc = (u - cx) * Z / fx
Yc = (v - cy) * Z / fy
Zc = Z
```

`Z` 一错，`Xc/Yc` 成比例放大错误。  
所以 **深度清洗在反投影之前**，比事后“修规划”便宜得多。

## 5. 本地单测怎么写（`test_depth_sample.py`）

| 用例 | 构造 | 期望 |
| --- | --- | --- |
| 正常平面 | 全 1.0 | 1.0 |
| 含坏点 | NaN/0/99 混在 1.0 里 | 仍 1.0 |
| 全零 | 不在值域 | None |
| 全 Inf | 非有限 | None |
| 越界索引 | u&lt;0 | None |
| 中位数 | 中心 3×3=0.8、外圈 1.2 | window=5→1.2；window=3→0.8 |

**注意：** window=5 时多数是 1.2，中位数 **不是** 中心 0.8——这是预期行为，不是 bug。

## 6. 设计取舍

1. **不改窗口为 7/9**  
   bbox 再大，中心块 5×5 在桌面场景够用；窗口太大易吃到背景。

2. **不引入 ICP / 拟合平面**  
   赛题时间紧；中位数性价比最高。

3. **与大模型深度并存**  
   YOLO 路径用相机深度；九格路径用模型输出 depth。  
   两路都要过值域，C++ 阶段1已对 `/model_output` 过滤。

4. **暂不支持 16UC1**  
   若云端 `rosbag` 显示编码不是 32FC1，再在 `depth_image_callback` 加 `/1000`。
