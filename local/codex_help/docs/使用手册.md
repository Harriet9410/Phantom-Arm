## 一、起栈（每次开始必做）

> 仿真启动的是**默认**场景（5 物品原始布局：烟雾弹×2、手电筒、弹夹、手雷）
> 
> 

```Bash
cd /root/tcei_final_v2_23/tcei_260920v2
bash robot.sh start bisai_stack_$(date +%m%d%H%M)
```

- 栈名**不能重复**（重名报 FileExistsError）；带时间戳写法永不重名

- 查已有栈名：`ls /root/gpufree-data/tcei_260920v2/`

- **就绪标志**：末尾出现 `已就绪，尚未下发抓取任务`（约 1\-2 分钟）

- 起栈即加载默认场景 \+ 五物体

### 1\.1 选择检测器

**九格（默认）/ YOLO（****`--detector`****）**

**默认 = 纯九格**，不加任何参数就是这个；只有做对照实验时才需要切：

```Bash
bash robot.sh start bisai_stack_$(date +%m%d%H%M)                 # 默认：纯九格（比赛形态）
bash robot.sh start yolo_stack_$(date +%m%d%H%M) --detector yolo  # 对照：检测器换成 YOLO
```

||纯九格（默认）|`--detector yolo`|
|---|---|---|
|分类/出框|九格大模型（FM9G4B\-V \+ LoRA）|YOLO（`/root/jaka/best.pt`）|
|YOLO 权重|**不加载**（零 YOLO 合规形态）|加载|
|语义规划（选哪个物体）|九格节点|九格节点（**仍然启动**）|
|用途|**比赛提交**|对照实验 / 九格故障时兜底|

切换只对**新起的栈**生效；已起的栈要停掉重新 `start`。

### 1\.2 场景与题库

**默认场景 / 指定布局（****`--case`**）

**不加 ****`--case`**** = 官方原场景**。仿真跑 `sim_with_feedback.py`，它直接 `import jaka_sim`（`/root/EAICON/Source/JAKA`）—— **官方 USD 原样，就是五件物资的原始摆放**（文件头注释："Original files stay intact"）。

**换一个布局**（还是官方那 5 件物资、只是摆放不同）—— **不用改代码**：

```Bash
bash robot.sh start <名> --case cases_official30_v2/official_random_05.json \
                        --case-register B02_AVAILABLE30_REGISTER.json
```

- 现成两套题库：`cases_b01/`（30 个，配 `B01_REGISTER.json`）、`cases_official30_v2/`（**官方30**，配 `B02_AVAILABLE30_REGISTER.json`）

- 带 `--case` 时起栈会换成 `harness/original_layout_sim.py`：按 case 摆位 → 等物理稳定 → 记真值 → 校验"都在筐内、互不重叠"；不通过会写 `scene_setup_error.json` 并**拒绝起栈**

**两条硬约束**

1. **case 必须已登记**：`verify_original_case()` 会校验 `sha256 + case_id + seed + planner_seed` 与 register 里某行**完全一致**，否则拒绝启动（防止偷换成早期种子）。

2. **`--case-register`**** 默认是 ****`B01_REGISTER.json`** —— 用官方 30 题库**必须显式传** `B02_AVAILABLE30_REGISTER.json`，否则报"不是已登记的 B01 布局"。

**case 的能力边界**：它按 **USD 原语路径**（`/World/Flashlight` 等）重新摆放**官方场景里已有的物体** —— **不能新增物体、也不能换场景**。

**换成别的情况呢？**

|换整个 USD 场景|**要****改代码**|`TCEI_SCENE` 换路径 \+ **相机内外参与手眼标定重做** \+ `perception.py` 投影常量 / `tcei_workspace.py` / `scene_layout_prior.json` 可能要改|
|---|---|---|

> 改 `tcei_stack/` 里任何文件都要**同步 ****`BUILD_MANIFEST.json`**（冻结运行时逐文件 sha256 校验）。
**缺口**：仓库里**没有生成 case 的脚本**。若现场只给"布局"不给 case 文件，得先写个生成器（读官方 USD → 采样合法位置 → 写 case \+ 登记）；若给了 case \+ register，直接放进来就能用。

## 二、发指令（两种方式）

### 方式一：终端逐条发

每次演练开始设会话号（回合名不重名）：

```Bash
S=$(date +%m%d%H%M)
```

**第 1 条（烟雾弹→左带）**

```Bash
bash robot.sh run ${S}_1 --instructions /root/gpufree-data/tcei_260920v2/drill5_instr_1.json --budget 210
```

> 成功标志：输出出现 **`task_succeeded`**（约 50\-70 秒）
> 出现 `rejected` / `task_failed` = 这条没拿到分，**照常做复位发下一条**，不影响后续
> 
> 

**复位（每条之后必须执行）**

```Bash
bash /root/gpufree-data/tcei_260920v2/manual_reset.sh
```

> 成功标志：**`RESET_OK`**（会附带一行 pids updated）
> 
> 

**第 2\-5 条（重复"发指令→复位"）**

```Bash
bash robot.sh run ${S}_2 --instructions /root/gpufree-data/tcei_260920v2/drill5_instr_2.json --budget 210
bash /root/gpufree-data/tcei_260920v2/manual_reset.sh

bash robot.sh run ${S}_3 --instructions /root/gpufree-data/tcei_260920v2/drill5_instr_3.json --budget 210
bash /root/gpufree-data/tcei_260920v2/manual_reset.sh

bash robot.sh run ${S}_4 --instructions /root/gpufree-data/tcei_260920v2/drill5_instr_4.json --budget 210
bash /root/gpufree-data/tcei_260920v2/manual_reset.sh

bash robot.sh run ${S}_5 --instructions /root/gpufree-data/tcei_260920v2/drill5_instr_5.json --budget 210
```

5 条指令文件内容（已在实例上，勿改）：

1. 抓取左上方的烟雾弹，放到左侧传送带

2. 抓取右下方的弹夹，放到右侧传送带

3. 抓取最左方的军用手电筒，放到左侧传送带

4. 抓取手雷，放到右侧传送带

5. 抓取剩余的物品，放到左侧传送带

**发第 N 条：**

```Bash
bash robot.sh run ${S}_N --instructions /root/gpufree-data/tcei_260920v2/drill5_instr_N.json --budget 210
```

- 成功标志：输出出现 `task_succeeded`（约 50\-70 秒）

- `rejected` / `task_failed` = 该条没分，复位后发下一条

- N = 1\~5 对应官方五条指令文件（已在实例上）：

    1. 抓取左上方的烟雾弹，放到左侧传送带

    2. 抓取右下方的弹夹，放到右侧传送带

    3. 抓取最左方的军用手电筒，放到左侧传送带

    4. 抓取手雷，放到右侧传送带

    5. 抓取剩余的物品，放到左侧传送带

**回合间复位**

> 每条指令跑完后必须执行
> 
> 

```Bash
bash /root/gpufree-data/tcei_260920v2/manual_reset.sh
```

成功标志：**`RESET_OK`**（附带 `pids updated`）
`RESET_FAIL`：再跑一遍；连续两次失败 → 走"万能恢复"

复位做三件事：杀 controller（清 cancelled 锁存）→ 清 sim 锁存 → 清回合锁 → 重启 controller → 回写 pids 台账。

**发自定义指令**：

```Bash
echo '["抓取右上方的手雷，放到左侧传送带"]' > /root/gpufree-data/tcei_260920v2/instr_custom.json
bash robot.sh run ${S}_N --instructions /root/gpufree-data/tcei_260920v2/instr_custom.json --budget 210
```

（json 数组格式，一条指令一个字符串；中文引号注意别敲错）

### 方式二：控制台图形化

```Bash
bash robot.sh console
```

桌面弹出控制台窗口（指令 1\~5 输入框已预填官方五条）：

1. **填指令**：每行一条；**只填想执行的条目**（留空的行不执行）

2. 点 **生成指令文件** → 日志显示 `指令文件已生成：.../manual_<时分秒>.json`

3. 点 **启动回合** → 状态区走"执行中…"，多条则同一回合内连续自动执行

4. 全部完成或被拒后，需要再跑一轮 → 点 **回合间复位** → 回到第 1 步

**多条填一回合 = 连打形态**：任何一条被拒 → 整回合终止，剩余不跑。

### 可视化开关（跟在 run 命令末尾）

|参数|效果|
|---|---|
|（不加）|无任何窗口|
|`--viewer`|弹出 bbox 实时小窗（800×450，框随物动 \+ 底部候选清单）|
|`--panel`|弹出核对面板（全功能：相机、标注、执行状态）|
|`--viewer --panel`|两个都弹|

示例：

```Bash
bash robot.sh run ${S}_1 --instructions ... --budget 210 --viewer
```

### 控制台 \+ bbox 小窗配合（零改动方案）

控制台的"启动回合"**不传 \-\-viewer 参数**，所以不会自动弹小窗。但 bbox 小窗是纯订阅者（只监听话题，不关心回合怎么发），**独立拉起一次即可持续显示**：

**先拉小窗（执行一次，持续挂着）**：

```Bash
cd /root/tcei_final_v2_23/tcei_260920v2
setsid nohup /usr/bin/python3 -u evaluation/bbox_window.py > /dev/null 2>&1 &
```

桌面上弹出 bbox 小窗，**不随回合结束关闭**，一直显示实时画面。

**再用控制台正常操作**：

```Bash
bash robot.sh console
```

填指令 → 生成 → 启动 → 看小窗里的实时标注和任务状态。发多少轮、怎么复位，小窗都在。

**不想看了直接点小窗 X 关掉。**

|组合|效果|
|---|---|
|小窗 \+ 控制台|图形化发指令 \+ 实时 bbox 画面（**训练推荐**）|
|小窗 \+ 终端逐条|终端发命令 \+ 实时画面|
|只开小窗|纯看画面不发指令|
|只开控制台|发指令不看画面|

> 核对面板（`bash robot.sh panel`）同理——也是纯订阅者，独立拉起即可与小窗/控制台并存。

## 三、核对成绩（全部跑完后）

终端逐条方式的回合名（$\{S\}\_N）：

```Bash
for r in ${S}_1 ${S}_2 ${S}_3 ${S}_4 ${S}_5; do echo "== $r =="; python3 -c "
import json
s=json.load(open('/root/gpufree-data/tcei_260920v2/$r/episode/summary.json'))
t=s.get('tasks',[{}])[0].get('result',{})
print(t.get('status'), 'placed=', t.get('placed_verified'))"; done
```

控制台方式的回合名（manual\_\<时分秒\>）：

```Bash
for r in /root/gpufree-data/tcei_260920v2/manual_*.json; do
  n=$(basename $r .json)
  ep=/root/gpufree-data/tcei_260920v2/$n/episode/summary.json
  [ -f "$ep" ] && python3 -c "
import json
s=json.load(open('$ep'))
tasks=s.get('tasks',[])
ok=sum(1 for t in tasks if (t.get('result') or {}).get('status')=='task_succeeded')
print('$n', '成功 %d/%d' % (ok, len(tasks)))"
done
```

## 四、清理

```Bash
# ① 停栈
cd /root/tcei_final_v2_23/tcei_260920v2 && bash robot.sh stop

# ② 强杀残留（stop 报错时）
pkill -9 -f "tcei_stack/(controller|nine_node|perception)[.]py"; pkill -9 -f "sim_with_feedback[.]py"; pkill -9 -f isaacsim

# ③ 清回合数据（释放磁盘；*_results*.json 保留）
cd /root/gpufree-data/tcei_260920v2 && rm -rf r[0-9]* drill5_[0-9]_* nine1* review_* manual_[0-9]*

# ④ 查磁盘（run_round 要求 ≥8GiB）
df -h /root/gpufree-data
```

> 修不好就整个重来
> 
> 

```Bash
pkill -9 -f "tcei_stack/(controller|nine_node|perception)[.]py"; pkill -9 -f "sim_with_feedback[.]py"; pkill -9 -f isaacsim; sleep 3
bash robot.sh stop 2>/dev/null; bash robot.sh start bisai_stack_$(date +%m%d%H%M)
```

重启栈 = 场景恢复原始 5 物体 = 需要从第 1 条重新开始。

## 六、测试工具

|工具|命令|用途|
|---|---|---|
|核对面板|`bash robot.sh panel`|看实时标注画面 \+ bbox \+ 任务状态（只读旁观件）|
