## 3. 命令序列（按顺序，任一步失败即停）

### 步骤 0（不加载模型，复核对齐）
```bash
cd /root && python3 ds_r9_train_lora_v2.py --dry-run
```
期望：`DRY-RUN OK … dataset 145 obs / 259 crops`；台账四层 = 场景 4 / 物体 ID 5 / 观测 145 / 裁剪 259。

### 步骤 1（仅 tokenizer+processor，复核对齐）
```bash
cd /root && /opt/conda/envs/inference/bin/python3 ds_r9_train_lora_v2.py --check-labels
```
期望：`image_token_span=[9,73]`（64 图像 token）、`kept_equals_expected: true`（答案掩码逐字正确）。
**若 `kept_equals_expected` 不为 true → 停止**（掩码错会训坏模型）。

### 步骤 2（训练前基线：复现在线旧路径的四类口径）
```bash
cd /root && /opt/conda/envs/inference/bin/python3 ds_r9_train_lora_v2.py --eval-holdout --baseline \
  | tee /root/r10_baseline_oldpath_holdout.json
```
说明：`--baseline` 会**包装旧 adapter 并禁用**（等价运行时的 `grounding=False`），得到与 R9 五类 `5/8/27` **不可直接比较**的四类基线。期望 `adapter_state: old_adapter_wrapped_and_disabled`。
**这是唯一允许"看结果"的一次评估**；看过之后不得据此改提示/改划分/改协议。

### 步骤 3（冒烟：真实前向+反向，单样本）
```bash
cd /root && /opt/conda/envs/inference/bin/python3 ds_r9_train_lora_v2.py --smoke \
  | tee /root/r10_smoke.json
```
必须同时满足，否则立刻停止并交日志：
- `device` 为 `cuda`；
- `loss_differs_with_other_image: true`（**换图确实改变了计算**）；
- `n_trainable_tensors_with_grad > 0`（答案区段确有梯度）；
- `targets` 全部以 `llm.` 开头且不含 `vpm./resampler./lm_head/score`；
- 打印的 `answer_span.kept_equals_expected` 为 true。

### 步骤 4（完整训练）
```bash
cd /root && /opt/conda/envs/inference/bin/python3 ds_r9_train_lora_v2.py --train \
  --epochs 4 --lr 1e-4 --rank 16 2>&1 | tee /root/r10_train.log
```
- 输出目录：`/root/sft_v2/outputs/r9_cls_lora_v2/step_<总步数>`（默认 train 160 裁剪 × 4 epoch = `step_640`）。
- 训练前会打印 LoRA 命中路径清单；**人工核对全部在 `llm.` 下**。
- 不覆盖旧 adapter；不改变运行包。

### 步骤 5（留出评估：新适配器）
```bash
cd /root && /opt/conda/envs/inference/bin/python3 ds_r9_train_lora_v2.py --eval-holdout \
  --adapter /root/sft_v2/outputs/r9_cls_lora_v2/step_<N> | tee /root/r10_holdout_new.json
```
判据（冻结协议 `r9_v0_class4_v1`）：`wrong_known == 0` 且 `protocol_failure == 0`，四类五件在生成预算内可判；同时给出 `per_object` 汇总。
**未过门 → 不接入运行版**；回到 R9 的数据/口径环节，不得改协议凑分。

### 步骤 6（仅在步骤 5 过门后）接入分类分支
- 新 adapter 目录与哈希锁定；
- 分类分支**必须**同时做两件事：把 adapter 指向 `r9_cls_lora_v2/step_<N>`，并**取消 `grounding=False` 的关闭行为**（仅改路径不生效）；
- 合入已复核的 C 修复；
- 之后再跑四个横平竖直场景的定向仿真。

## 4. 失败停止条件（逐条）

| 触发 | 动作 |
|---|---|
| 步骤 0/1 的哈希、台账或掩码断言不符 | 停止，报差异，不进入训练 |
| 步骤 3 任一断言不满足（尤其换图 loss 不变） | **立即停止**，交 `r10_smoke.json`：说明训练不会学到视觉 |
| 训练 loss 非有限值 / 显存 OOM | 停止并交日志；**不得**靠改协议或减数据绕过 |
| 步骤 5 有 `wrong_known` 或 `protocol_failure` | 不接入运行版；交逐物体明细 |
| 定向仿真出现新误抓、碰撞或未恢复掉件 | 停止接入，保留原帧与事件 |
| 任何时刻需要改冻结协议 | 产出新 `protocol_id` 与新文件，旧文件保留 |
