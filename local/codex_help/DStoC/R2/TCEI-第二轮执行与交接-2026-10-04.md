## 4. R2-0.3 区域时序：两族失败的结构（关键更正）

**阻断区（multiple_body_cores / unresolved_correspondence）与 last-seen 区（unobserved_unverified_object）必须分开**：

| 案例 | 持续阻断区 | 结论 |
| --- | --- | --- |
| scramble_01 | 无持续阻断区（仅瞬时 unresolved_correspondence，n≤86） | 失败纯因**分类**（手雷被读成烟雾弹） |
| scramble_02 | 无持续阻断区（瞬时，n≤67） | 手电筒被拒原因**待查**（非持续阻断区；可能为分类或瞬时身份） |
| scramble_03 | **[762,344,826,358]（64×14=896px²，GT=手电筒）从第一帧持续到回合结束** | 手电筒无候选 + 该区被标类后产生幻影候选 |
| scramble_04 | 同上（sim −1..311） | 同上 + **幻影第二 Grenade**（`Grenade:ambiguous:896`） |
| scramble_05 | **[462,174,525,188]（63×14，GT=手电筒）sim 15..384** | 手电筒任务 1 即被拒 |

- **896px² 区域的真身 = 手电筒自己的框**（64×14），不是独立碎片——"单一歧义区域导致全部失败"不成立，但"**手电筒框被深度分割成多核 → 身份 ambiguous → 手电筒任务必拒 + 该区被赋予类别后成为幻影同类**"这条链在 03/04/05 成立。
- **为什么 01/02 没有持续阻断区**：01/02 的手电筒在任务 3 被成功抓走，区域随后消失；03/04/05 的手电筒从未被抓起（其任务被拒）→ 区域全程存在。**先有阻断区还是先有拒单**：03/05 的阻断区从首扫（sim≈−1/15）就存在 → 区域在先，拒单在后。
- last-seen 区（unobserved_unverified_object）多为**已交付/被遮挡物体的最后可见框**，n 很大但属正常现象；它们对第 5 项的影响是"已知身份不可见 → 剩余集不完整"，需逐身份核对是否已交付（后续用 episode 事件对账）。
- **待补**：`scramble_02` 手电筒被拒的精确机制（本目录证据不足以定论，两种备选：分类错标 / 瞬时对应失败）。

**判据**：两核连线上 body 最窄宽度 ≥4px → 颈部不断 → 单物体（头+柄渐变）；两件接触物体的接触颈 ≤2-3px → 维持 multiple_body_cores。单测：手电筒剖面（7px）判单 ✓、接触物剖面（2px）判两 ✓。时序判据（§6 分核占比）保留处理闪烁情形。
