## 1. 当前结论

R9 原版**不能直接训练并宣称过门**：其评估读取不存在的协议字段、逐裁剪而非逐观测计分，冒烟比较的是可能同源的图片且 dropout 未关闭。更关键的是原数据生成器把 31 个手电筒的 0.25 边距窄视图全部过滤，原集只有 145 次观测 / 259 张裁剪，无法执行“双视图一致”协议。上述问题不是换一个超参数可以解决的。

Codex 已在服务器**新建** R10 数据集、协议、训练入口；R9 原文件、旧定位 adapter 和运行包保持原状。新集为 145 次观测 / 290 张裁剪，训练 s01+s02 为 89 次观测 / 178 张裁剪，留出 s03+s04 为 56 次观测 / 112 张裁剪；每次观测都严格有 0.25 和 0.85 两视图。训练集仅有 22 张不同源图，留出 13 张，且两侧共享五个资产 ID；**离线通过只能说明同资产换摆位，不能推断实机泛化。**

## 5. DS 执行顺序（完成安全门后开始模型步骤）

DS 可以先只读核对文件 SHA 和数据数量；模型步骤由 DS 执行，Codex 不代跑。统一使用 /opt/conda/envs/inference/bin/python3；所有管道先设置 set -o pipefail，日志写 /root/gpufree-data/r10_run/，保留原始 stdout/stderr、退出码、命令、脚本/协议/清单 SHA。不要覆盖旧日志。

~~~bash
set -euo pipefail
cd /root
mkdir -p /root/gpufree-data/r10_run
sha256sum ds_r10_train_lora_v3.py ds_r10_eval_protocol_v2.json /root/gpufree-data/r10_dataset/manifest.json
/opt/conda/envs/inference/bin/python3 ds_r10_train_lora_v3.py --dry-run
/opt/conda/envs/inference/bin/python3 ds_r10_train_lora_v3.py --check-labels
~~~

上面两步只做数据/Processor 检查。需看到 145/290、每观测两视图、四类有效答案掩码；任一不符立刻停。

随后 DS **仅依次**执行：

1. --eval-holdout --baseline：冻结四类口径的旧在线分类基线。保存逐观测原始 JSON；看过结果后不能改提示、协议、数据划分或候选阈值。
2. --smoke：真实多模态前后向及一个未保存的优化步；同图重复与不同源图保持相同提示/答案的对照必须过门，CUDA、finite loss、LoRA 非零梯度、参数路径及峰值显存都须记录。脚本失败应非零退出。
3. --train --epochs 4 --lr 1e-4 --rank 16：只在前两门通过后运行一次；输出应为 /root/sft_v2/outputs/r10_cls_lora_v2/step_712。训练日志必须含 4 个 epoch 样本/步数/loss/峰值显存。
4. --eval-holdout --adapter /root/sft_v2/outputs/r10_cls_lora_v2/step_712：新 adapter 留出评估。核对 JSON 的 offline_gate.pass、56 条观测记录、每视图原文、十组资产结果及 SHA。

对应命令如下。**DS 每完成一行先确认退出码和日志，再执行下一行；不要整段粘贴后台运行。**

~~~bash
set -o pipefail
/opt/conda/envs/inference/bin/python3 /root/ds_r10_train_lora_v3.py --eval-holdout --baseline 2>&1 | tee /root/gpufree-data/r10_run/01_baseline.log
/opt/conda/envs/inference/bin/python3 /root/ds_r10_train_lora_v3.py --smoke 2>&1 | tee /root/gpufree-data/r10_run/02_smoke.log
/opt/conda/envs/inference/bin/python3 /root/ds_r10_train_lora_v3.py --train --epochs 4 --lr 1e-4 --rank 16 2>&1 | tee /root/gpufree-data/r10_run/03_train.log
/opt/conda/envs/inference/bin/python3 /root/ds_r10_train_lora_v3.py --eval-holdout --adapter /root/sft_v2/outputs/r10_cls_lora_v2/step_712 2>&1 | tee /root/gpufree-data/r10_run/04_holdout.log
~~~

每一条命令均单独执行并写独立日志；不要将四步拼成无人值守脚本。出现 OOM、NaN、协议失败、脚本异常或 offline_gate.pass=false，**停止，不接入运行包**，把最小失败证据交给 Codex 决策。过门后也先交 Codex 审核，再决定适配器切换和在线仿真。
