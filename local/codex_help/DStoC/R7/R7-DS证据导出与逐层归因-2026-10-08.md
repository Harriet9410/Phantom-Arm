## 3. 逐层首次异常（R7-0 第 4 项要求的四层对齐）

### 3.1 关键阶段原始答案（决定性）
同一真实物体（s02/s04 该位置真值均为 **Smokegrenade**）：

| 阶段（tag） | s02 `2bd402ef17:p2`（锁定 Torch 那次） | s04 `4be9fc1aae:p2` |
|---|---|---|
| `crop_en` | 「这个物资是**手榴弹**。」 | 「这个物资是**手榴弹**。」 |
| `crop_zh` | `Grenade` | `Grenade` |
| `recheck_gt` | 「这个物体是**手雷（Grenade）**…」（长推理，2 票一致） | 「这个物体是**手雷（Grenade）**…」（2 票一致） |
| **`final`** | **「Torch（军用手电筒）」**（2 票一致） | **「Torch（军用手电筒）」**（2 票一致） |
| 审计 `scan_class` | **Torch** | **Torch** |

对照 s04 恢复那次 `9eb70567c0:p1`：`crop_en`=手榴弹、`crop_zh`=Grenade、`recheck_gs`=**Smokegrenade**、`final`=**Smokegrenade** → 审计 `scan_class`=Smokegrenade。

**事实**：`scan_class` 的取值等于 `final` 阶段（四选一）的裁决。
**事实**：`final` 的裁决与本物体全部上游阶段（crop_en / crop_zh / recheck_gt）**矛盾**——上游一致说 Grenade，四选一说 Torch。
**代码依据（`nine_classify.py::_classify_proposals`）**：终审是最后一个写 `assign[i]` 的环节，且**无条件覆盖**：
```
ans = _recheck_agree(bbox, FIVE_PROMPT, tag='%s:p%d:final' % ...)
if ans in declared and ans != cls:
    assign[i] = ans          # 覆盖此前 crop/GS/GT 的一致结论
```
`FIVE_PROMPT` 为四选一（Smokegrenade/Grenade/Torch/Magazine）。因此**同一物体两选一（Grenade/Torch）答 Grenade、四选一答 Torch，且四选一因位于最后而获胜**。

4. **未发现遮挡/深度团块被当作物资的确证**：两案目标物体的 bbox 稳定在 `[641,339,697,361]`（56×22px），非碎片尺度；`unknown_regions` 全程为空。但**未能排除**——本轮无逐帧候选可查，此项**列为未证实**。
