# 比赛所需技能 — 从零学习 + 速成指南

> 依据：`docs/比赛技术路线与任务清单.md`

> 原则：**先会用 → 再改参 → 再改逻辑**；时间紧时走「速成路径」，时间够再补系统课

## 0. 怎么用这份文档

| 你的状态 | 怎么读 |
|---|---|
| 完全零基础 | 按「推荐学习顺序」走；每项先做 **速成 2 小时清单**，再补「从零完整路径」 |
| 会 Python 但不懂机器人 | 跳过 Python 基础；主攻 ROS、坐标、抓取状态机 |
| 会机器人不懂 CV/大模型 | 主攻 YOLO/OpenCV/Prompt；控制侧可先用现成接口 |
| 只剩 1～2 周 | 只做各节「速成」+ 文末 **7 天冲刺表** |

**推荐学习顺序（全局）：**

```
① Linux + Python 读代码
② ROS1 话题/节点（跟本赛 topic 表）
③ 坐标系：像素→相机→机器人（和 6.2 外参一起学）
④ YOLO / 深度 / 倾斜角（感知）
⑤ 大模型 Prompt + model.chat（指令解析）
⑥ 抓取状态机 + 夹爪增量（操作）
⑦ TRRT* / RmpFlow 调参（官方开放优化）
⑧ 可选：LoRA / 量化 / TSP 顺序
```

## 2. 全局底座（从零必会）

### 2.1 Linux 终端（速成 2 小时）

**从零完整路径：**  
通读「文件系统、cd/ls/cat/grep、权限、环境变量」任意一门 Linux 入门（不必装真机，云桌面即可）。

**速成清单（当天就能干活）：**

| 命令 | 用途 |
|---|---|
| `cd` / `ls -la` / `pwd` | 找目录、看文件 |
| `cat` / `less` / `grep -n 关键词 文件` | 读代码、搜字符串 |
| `echo $PATH` / `source ~/.bashrc` | 环境变量 |
| `df -h` / `du -sh 目录` | 磁盘（系统盘 vs 数据盘） |
| `nvidia-smi` | 看显存与 GPU |
| `conda activate xxx` / `conda env list` | 多环境 |

**验收：** 能在镜像里 30 秒内打开 `isaac_grasp.cpp` 并搜到 `waitForGripper`。

---

### 2.2 Python 读改（会则跳过）

**从零：** 变量、函数、类、列表字典、文件读写、`cv2`/`numpy` 基础即可；**不必**先学深度学习框架。

**速成（针对本赛代码）：**

1. 打开 `isaac_yolov8.py`：找出「订阅回调 → predict → 发布」三段  
2. 打开 `isaac_scale.py`：找出「加载模型 → 收图 → `model.chat` → 发字符串」  
3. 改一处日志 `print`/`rospy.loginfo`，重跑节点确认能打出

**验收：** 能说清「YOLO 节点输入哪个 topic、输出哪个 topic」。

---

### 2.3 C++（只读不从零写）

**不要**从头学 C++ 模板/多继承。只认这些模式：

| 模式 | 在代码里的样子 |
|---|---|
| 回调 | `void xxCallback(...)` + `nh.subscribe` |
| ROS 发布 | `nh.advertise` + `pub.publish` |
| 状态机 | `doPickPlace()` 里顺序 `waitFor*` |
| 计时/等待 | `waitForPosition` / `sleep` / timeout |

**速成 3 小时：** 在 `isaac_grasp.cpp` 里把 `doPickPlace` 用中文旁注标成 8 步清单。

## 3. ROS1（核心底座）

### 从零完整路径（3～5 天）

1. 概念：节点、话题、消息、launch（半天）  
2. 官方 turtlesim + 本赛「roscore / 五终端」对照（1 天）  
3. `rostopic list/echo/hz`、`rosnode list`（1 天）  
4. 读本赛 `readme.txt` + 技术路线 §3.3 话题表，边跑边 `echo`（1～2 天）

### 速成（0.5～1 天，直接对标赛题）

**只学这些命令：**

```bash
roscore
rostopic list
rostopic echo /Jaka/gripper_is_captured
rostopic hz /Jaka/camera_rgb
rosnode list
rosnode info /isaac_grasp   # 名字以实际为准
```

**对照表学（比抽象 ROS 课快 10 倍）：**

| 现象 | 看哪个话题 |
|---|---|
| 仿真没起 | 终端二日志、`/clock` |
| 看不见画面 | `/Jaka/camera_rgb` |
| 机械臂不动 | `/Jaka/set_end_effector_pose` 是否有人发 |
| 抓不住 | `/Jaka/gripper_is_captured` |
| 模型没输出 | `/model_output`、`/yolo_annotated_image` |

**验收：** 仿真跑着时，不看代码也能用 `rostopic echo` 判断「卡在感知、决策还是执行」。

## 4. 坐标与标定（目标识别 + 路径的交叉点）

### 从零（2～4 天）

1. 相机内参 \(f_x,f_y,c_x,c_y\)：`/Jaka/camera_info` 的 `K`  
2. 像素 → 相机：  
   \(X_c=(u-c_x)d/f_x,\; Y_c=(v-c_y)d/f_y,\; Z_c=d\)  
3. 相机 → 机器人：\(P_{robot}=R P_{cam}+T\)  
4. 四元数只记：和旋转矩阵可互转，控制里发 pose 用四元数即可  

**练习：** 拿一张已知物体在图像中心的帧，手算一遍 X,Y,Z，再和代码结果对一下。

### 速成（半天）

1. 只背公式 + 两步变换  
2. 打开源码找到 **写死的 R、T**，改 T 的 x 加 1cm，看抓取点是否跟着偏  
3. 用棋盘格脚本 `run_jaka_checkerboard_sim.sh` 跑一遍「能标定」即可  

**验收：** 能解释「识别对了但抓偏」优先查 R/T 还是查深度。

## 5. 感知：YOLO + OpenCV + 深度

### 从零路径

| 主题 | 学什么 | 练什么 |
|---|---|---|
| YOLO | `model.predict`、框、置信度、类别 | 读 `isaac_yolov8.py` 预处理与结果遍历 |
| 深度图 | 32FC1=米；中心像素；无效值 | 对 `/Jaka/camera_depth` `echo` 或存图看范围 |
| 倾斜角 | Canny → 轮廓 → `minAreaRect` | 改阈值看 angle 是否跳变 |
| ROI | bbox 裁剪再检测 | 小目标：对 bbox 外扩再推理 |

### 速成（0.5～1 天）

1. **不训练模型**，只做后处理稳定：  
   - 深度：中心点周围取中值/均值，滤掉 0 与超大值  
   - 角度：与上次帧差过大则沿用旧值  
2. 用 YOLO 窗口确认「烟雾弹/饮料」始终出框  
3. 把 (u,v,depth,angle) 打成一行日志，和下游 C++ 解析格式对齐  

**验收：** 同一指令连跑 5 次，检测日志格式一致、无 NaN。

## 6. 大模型：指令解析 + 九格 BBox

### 从零路径（1～3 天，不必先学 Transformer）

1. 会跑：`conda activate inference` + `test.py`（你已具备）  
2. 会读 `isaac_scale.py`：订阅什么图、如何 `chat`、发什么字符串  
3. **输出契约**（最重要）：Prompt 里写死模板，例如：

```text
只输出一行：bbox_u,bbox_v,depth_m,angle_deg,class
不要解释。
示例：256,312,0.85,12,grenade
```

4. 解析端：C++/Python 按同一格式取数；失败则丢弃该帧  

### 速成（2～4 小时 — 性价比最高）

| 步骤 | 动作 |
|---|---|
| 1 | 只改 Prompt，加「禁止多余文字 + 示例」 |
| 2 | 打印 `model.chat` 原始返回，看是否总能正则抠出 4 个数 |
| 3 | 失败重试 1 次；连续失败则跳过该目标 |
| 4 | 对比：纯文字指令 vs 带 YOLO 标注图的识别率 |

**关于「九格替换 YOLO」：** 官方允许。速成策略是 **先保 YOLO 出框，大模型只做「选哪一框 + 姿态」**；全替换 BBox 需要更稳的输出契约与数据，属加强项。

### LoRA / 量化（可选，非赛前默认）

| 项 | 建议 |
|---|---|
| LoRA | 有标注数据、有 3 天以上再动；先读官方 `finetune/` 与 4090 适配笔记（梯度累积、路径进数据盘） |
| 量化 | 4090 bf16 已够推理；仅共卡/显存紧时再学 int4 概念 |

**验收：** 10 条随机指令里，≥8 次能解析出合法 (u,v,depth,angle)。

## 7. 操作：抓取状态机 + 夹爪

### 从零（2 天读代码，不重写）

对照 `isaac_grasp.cpp` 的 `doPickPlace`：

```
收目标 → 抬升 → 等到位 → 下降 → 等到位 → 延时 → 闭爪(增量)
  → 等 captured → 回初始 → 放置位1 → 放置位2 → 开爪 → 回初始 → 发结果
```

夹爪：

```
读当前值 g → 发 g+0.001 → 看 /Jaka/gripper_is_captured
True 停；False 继续；设最大次数防止死循环
```

### 速成（3 小时）

| 改什么 | 目的 |
|---|---|
| 接近高度（z 偏移） | 减少空抓/撞桌 |
| 闭爪前延时 | 等臂稳 |
| 最大增量次数 | 防卡死 |
| 放置位姿 | 传送带左/右 |

**验收：** 换「饮料」指令，对比改前改后成功率各 5 次。

## 8. 路径规划：TRRT* + RmpFlow（官方开放优化）

### 从零直觉（不要先啃论文，3～5 天）

| 算法 | 一句话直觉 | 你改什么 |
|---|---|---|
| TRRT* | 随机试路径；温度**拒绝**太猛的跳；邻域 **rewire** 变短 | `step_size` `radius` `max_iter` `init_temp` |
| RmpFlow | 末端被「吸」向目标，同时躲障碍（反应式） | 子步长、目标帧、是否忽略 state 更新 |
| 轨迹跟踪 | 规划好的路按时间插值下发关节 | duration、插值、是否每帧刷新 |

### 速成（1 天）

1. 只调 **一个变量** 时，记录：规划时间、是否抖、是否撞  
2. 顺序建议：`step_size` → `max_iter` → `duration`（快慢）→ 最后再碰温度  
3. 用固定初始关节 + 固定目标位姿做 **A/B 对照**，禁止同时改三个参数  

**验收：** 同一目标 10 次规划成功，平均时间与成功率有表格。

## 9. 鲁棒分拣 + 工程习惯

### 从零速成包

1. **失败分类：** 空抓 / 超时 / IK 无解 / 模型无输出 / 规划失败  
2. **重试：** 回初始 → 最多 N 次 → 仍失败则跳过并记日志  
3. **观测：**  
   `rostopic echo /pick_place_result`  
   节点日志带时间戳  
4. **多目标：** 队列去重；先抓近的或按类别优先级
