## 七、`state/instance.env` 是什么

**一句话**：它是这个包的**"机器相关配置"**——把代码和"这台机器上的具体路径"解耦。**由 `bash robot.sh init` 生成，之后每次跑 `robot.sh` 都自动加载。**

### 7.1 它存在的理由

`tcei_stack/` 里所有模块**不写死绝对路径**，而是读这些 `TCEI_*` 变量。换一台实例，只需重跑 `init` 重新生成这个文件，**代码一行都不用改**（"同一份包，换机器就能跑"就是靠它）。

### 7.2 生成与加载链

```
bash robot.sh <子命令>
  └─ scripts/env.sh                     ← 每个子命令都会先跑它
       ├─ TCEI_PACKAGE_ROOT = 本包根目录（由 robot.sh 自身位置推得）
       ├─ 若没有 state/instance.env → 提示"请先运行 bash robot.sh init" 并退出
       ├─ source state/instance.env     ← ★ 就是在这里生效的
       ├─ export TCEI_HARNESS
       └─ source /opt/ros/noetic/setup.bash、/root/jaka/devel/setup.bash
          并把 cudnn / cuda 加进 LD_LIBRARY_PATH

bash robot.sh init                       ← 生成它
  └─ scripts/setup.py                    ← 逐行写 export K=shlex.quote(V)
       同时写 state/INSTANCE_ID.txt 与 state/configuration.json
```

### 7.3 变量表（本实例实读）

| 变量 | 值 | 谁在用 |
| --- | --- | --- |
| `DISPLAY` | `:20.0` | 仿真图形界面 |
| `TCEI_PACKAGE_ROOT` | `/root/tcei_final_v2_23/tcei_260920v2` | `env.sh`、各脚本 |
| `TCEI_CODE` | `…/tcei_stack` | `launch_stack` 拼 4 个节点的路径 |
| `TCEI_RUNS` | `/root/gpufree-data/tcei_260920v2` | 每轮证据落盘位置 |
| `TCEI_SCENE` | `/root/EAICON` | 场景与官方仿真 |
| `TCEI_MODEL` | `/root/inference/FM9G4B-V` | `nine_node` 加载大模型 |
| `TCEI_WEIGHTS` | `/root/jaka/best.pt` | `perception` 的 YOLO 权重 |
| `TCEI_ISAAC_PY` | `/root/isaacsim/python.sh` | sim 节点解释器 |
| `TCEI_YOLO_PY` | `/opt/conda/envs/yolov8/bin/python` | perception 节点解释器 |
| `TCEI_NINE_PY` | `/opt/conda/envs/inference/bin/python` | nine 节点解释器 |
| `TCEI_ROBOT_CALIBRATION` | `…/calibration/robot_projection.static_checked_v1.json` | controller 的投影像元排除 |
| `TCEI_INSTANCE_FILE` / `TCEI_INSTANCE_ID` | `state/INSTANCE_ID.txt` / `gpufree-container-01b232885b01` | **实例身份校验**（见下） |
| `ROS_MASTER_URI` | `http://127.0.0.1:11311` | ROS master（**只允许本机**） |
| `TCEI_V7_CODE` / `TCEI_V7_RUNS` | 与 `TCEI_CODE`/`TCEI_RUNS` 相同 | **遗留别名**（旧命名，保留兼容） |
| `TCEI_DETECTOR`（本轮新增，默认不写） | 未设 = `nine` | 检测器开关（`--detector` 优先） |

### 7.4 两个安全设计

1. **实例身份绑定**：`TCEI_INSTANCE_ID` 必须与 `state/INSTANCE_ID.txt` 内容一致 —— `launch_stack.verify_resources()` 启动时校验，**不一致直接拒绝起栈**（防止把在别的实例上 `init` 过的包拿来跑，从而用错标定/路径）。
2. **只允许本机 ROS**：`ROS_MASTER_URI` 的 host 必须是 `localhost` / `127.0.0.1` / 本机名，否则 `launch_stack` 拒绝启动（不允许连外部 master）。

### 7.5 ⚠️ 注意

- 这是**每台实例特有**的文件（值是路径 + 容器 ID）。**换实例必须重跑 `bash robot.sh init`**，别照抄。
- 仓库/归档里若存着历史那一份，只是快照，**不要直接覆盖**当前实例的版本。
- 它**已被服务器 git 跟踪**（`state/instance.env` 在 `git ls-files` 里）。
