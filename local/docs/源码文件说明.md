### 1.2 EAICON/Source/JAKA/jaka_sim.py (341行) ⭐ 仿真主入口

**作用**: JAKA 机械臂独立仿真场景的主程序，负责场景搭建、ROS通信、主循环。

**启动方式**: `sh run_jaka_sim.sh`

**关键流程**:

```
main()
  └─ SimEnvironment(kit)     # 初始化仿真环境
       ├─ open_stage()       # 加载 USD 场景文件
       ├─ init_ros()         # 初始化 ROS 节点
       ├─ add_ros1_camera()  # 配置相机 RGB/Depth/Info
       ├─ JakaRmpFlowController()  # 创建机械臂控制器
       └─ play() → step()   # 主循环
```

**SimEnvironment 类关键方法**:

| 方法 | 说明 |
|---|---|
| `__init__()` | 加载场景、初始化 ROS pub/sub、配置 ActionGraph、创建相机 |
| `play()` | 重置世界 + 播放仿真 |
| `step()` | 每帧: 检测新目标 → 调规划 → 调跟踪 → 发布 ROS 数据 |
| `publish_ros_data()` | 发布末端位姿、关节状态、夹爪力、抓取状态 |
| `reset()` | 重置机械臂 + 重置全局状态变量 |

**ROS 话题配置**:
- 订阅: `/Jaka/set_end_effector_pose`, `/Jaka/set_gripper_value`
- 发布: `/Jaka/get_end_effector_pose`, `/Jaka/get_jointstate`, `/Jaka/get_gripper_efforts`, `/Jaka/gripper_is_captured`

## 二、jaka — ROS catkin 工作空间

### 2.1 jaka/src/jaka_arm/ — 抓取执行包

#### 2.1.1 src/isaac_grasp.cpp (360行) ⭐ 抓取状态机

**作用**: C++ 实现的 pick-and-place 完整状态机。

**PickAndPlaceNode 类关键方法**:

| 方法 | 说明 |
|---|---|
| `doPickPlace()` | **主流程**: 抬升→接近→下降→闭合夹爪→回到初始→移动到放置位→释放→回到初始 |
| `waitForPosition()` | 等待末端到达目标位姿（位置+姿态容差判断） |
| `waitForGripper()` | 等待夹爪确认闭合（增量递增 + 力传感器反馈） |
| `controlGripperIncremental()` | 夹爪增量控制: 每次 ±0.001m |
| `openGripperDirectly()` | 直接设置夹爪为打开状态 (0.001) |

**状态机流程**:
```
收到目标 → 抬升至目标上方(+z) → 等待到位
  → 下移至抓取点 → 等待到位 → 延时5s → 闭合夹爪
  → 等待抓取确认 → 回到初始位姿 → 等待到位
  → 移动至放置位1 → 等待到位
  → 移动至放置位2(下降) → 等待到位 → 延时3s
  → 夹爪打开 → 延时2s → 移动至放置位3(上升)
  → 等待到位 → 回到初始位姿 → 发布结果
```

**ROS 接口**:
- 订阅: `/conveyor_side`, `/arm_end_pose_quaternion`, `/Jaka/get_end_effector_pose`, `/Jaka/gripper_is_captured`
- 发布: `/Jaka/set_end_effector_pose`, `/Jaka/set_gripper_value`, `/pick_place_result`

### 2.2 jaka/src/large_scale_model_arm/ — 视觉+大模型+抓取包

#### 2.2.1 scripts/isaac_yolov8.py (173行) ⭐ YOLO 检测节点

**作用**: 订阅 RGB+Depth 相机，运行 YOLOv8 目标检测，发布检测结果。

**YoloPublisher 类关键流程**:
```
订阅 /Jaka/camera_rgb → RGB图像回调
订阅 /Jaka/camera_depth → 深度图回调
  └─ process_yolo_results()
       ├─ self.model.predict(rgb_image)  # YOLO 推理
       ├─ 遍历每个 bbox:
       │   ├─ 提取中心像素深度值
       │   ├─ compute_2d_tilt(roi)  # Canny+minAreaRect 计算倾斜角
       │   ├─ 标注图像 (bbox + 深度 + 角度)
       │   └─ 发布 Mycaryolo 消息
       └─ 发布 /yolo_annotated_image
```

**关键函数**:
- `compute_2d_tilt()`: Canny 边缘检测 → 形态学闭合 → 轮廓提取 → minAreaRect → 倾斜角
- `convert_pixel_to_camera_coordinates()`: 像素坐标 → 相机坐标系

---

#### 2.2.2 scripts/isaac_scale.py (163行) ⭐ 大模型推理节点

**作用**: 加载九格 FM9G4B-V 大模型，接受文本 prompt，对 YOLO 标注图像做场景理解。

**ImageProcessorNode 类关键流程**:
```
加载 FM9G4B-V 模型 (AutoModel + AutoTokenizer)
订阅 /yolo_annotated_image
命令输入线程 (terminal input)
  └─ process_latest_frame()
       ├─ BGR→RGB→PIL.Image
       ├─ 构造 msgs: [{role: 'user', content: [image, prompt]}]
       ├─ self.model.chat(image=None, msgs=msgs, tokenizer=...)
       └─ 发布 /model_output (字符串)
```

---

#### 2.2.3 src/isaac_yolov8.cpp (169行) ⭐ 模型输出解析

**作用**: C++ 解析大模型输出的文本，用相机外参转换为机器人坐标系下的抓取位姿。

**ModelToArmNode 类关键流程**:
```
订阅 /model_output → modelCallback()
  ├─ 解析 JSON 或正则提取 (u, v, Z, angle)
  ├─ 像素→相机坐标: Xc=(u-cx)*Z/fx, Yc=(v-cy)*Z/fy
  ├─ 相机→机器人坐标: P_robot = R * P_camera + T
  ├─ 构造四元数 (roll=-3.13, pitch=0.031, yaw=-0.19)
  └─ 发布 /arm_end_pose_quaternion (7D向量)
```

**相机外参**:
```python
R = [0.9499, -0.0767,  0.3030]
    [0.1082,  0.9902, -0.0887]
    [-0.2932, 0.1170,  0.9489]
T = [0.5072, 0.2223, 0.3310]
```

---

#### 2.2.4 src/isaac_pose_pub.cpp (154行)

**作用**: 另一种坐标转换方式，从 bbox + depth 直接计算末端位姿。

**ArmEndPosePublisher 类**: 订阅 `/yolo_annotated_image` 和 `/camera_pose`，用相机内参 + 外参做坐标转换。

**与 isaac_yolov8.cpp 的区别**:
- isaac_yolov8.cpp: 解析大模型文本输出
- isaac_pose_pub.cpp: 直接接收 JSON bbox 数据

### 7.5 总结

**本地 `source_code` 与云端 `/root/` 的核心源码完全对上**，30 个源码文件一一对应。

本地缺少的是环境类文件（IsaacSim 安装、YOLOv8 源码、大模型权重），这些不需要版本管理，在云端直接安装/下载即可。

本地多出的是 Go2 机器狗赛道的代码和资产，与我们机械臂赛道无关。
